NotificationIconSnapshot

class NotificationIconSnapshot

Immutable in-memory snapshot of a selected ANIP icon catalog.

Every icon in icons has a successfully loaded bitmap. The snapshot strongly retains those bitmaps until the snapshot itself becomes unreachable.

Parameters

icons

icons whose bitmaps were loaded successfully.

memorySizeBytes

bitmap allocation size with shared bitmap instances counted once.
