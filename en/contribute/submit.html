Ready to Submit ​

ANIP now supports an automated icon adaptation resource contribution process. You only need to select, debug, and create an issue with one click on this page.

Select or drag a PNG, SVG icon here
Try finding a ready-made layered app icon in Perfect Icons Completion Project and modify it for your adaptation.

Enabling this option will force all notification icons pushed by the app to be overlaid, regardless of whether they are native monochrome or not. It is not recommended to enable this option by default.

Review Criteria ​

  • Icon resources should be monochrome, have a transparent channel, and are recommended to be square with a size of no less than 50 px, no more than 150 px, and a size of no more than 24 KiB
  • If "Overlay" is checked, please be sure to explain the reason in the remarks. Otherwise, it may be rejected
  • When modifying an adapted resource, you are not allowed to adjust the target app and can only append new contributors. You must explain the reason for the modification in the remarks, otherwise it may be rejected. Changes to contributors or remarks alone will not be considered valid modifications

Precautions ​

  1. Please make sure you have contacted the app developer first if possible, as we recommend that you contact the app developer to adapt the notification icon themselves before contributing an icon resource here.
  2. The previous Notification Icon Debug Tool v1.1 has been deprecated. Please follow the automated process on this page. We no longer accept icon resources validated through this tool.
  3. The automated process is now relatively complete. Under normal circumstances, we do not accept icon resources submitted via manual PRs (they will be closed and marked as invalid). Please follow the automated process for submissions. Contributions to other aspects of the project, outside the icon resource contribution process, are not subject to this restriction.
