# 请求适配

> 欢迎为通知图标适配计划 (ANIP) 贡献宝贵资源！

## 如何提交

目前的提交适配请求方式为在 GitHub 创建一个 Issue。

你需要前往 GitHub 使用通知图标适配模板创建一个 Issue。

管理员看到你创建的 Issue 后会进行处理，最快 1-3 个工作日内完成。

适配完成后 Issue 会被关闭并标记为完成，同步云端规则即可获取最新的适配数据。

如果你没有 GitHub 账号，请先注册，[点击这里](repo://issues/new?template=request_adaption.yml) 立即创建一个 Issue。

## 提交前须知

可优先联系到应用开发者的，我们建议优先联系应用开发者自行适配通知图标，而不是前往这里提交 Issue。

已有图标适配资源？请前往 [准备提交](./submit.md) 页面。
