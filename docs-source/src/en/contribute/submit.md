# Ready to Submit

> ANIP now supports an automated icon adaptation resource contribution process. You only need to select, debug, and create an issue with one click on this page.

<SubmitAdaption />

## Review Criteria

- Icon resources should be monochrome, have a transparent channel, and are recommended to be square with a size of no less than 50 px, no more than 150 px, and a size of no more than 24 KiB
- If "Overlay" is checked, please be sure to explain the reason in the remarks. Otherwise, it may be rejected.

## Precautions

1. The previous **Notification Icon Debug Tool v1.1** has been deprecated. Please follow the automated process on this page. We no longer accept icon resources validated through this tool.
2. The automated process is now relatively complete. Under normal circumstances, we do not accept icon resources submitted via manual PRs (they will be closed and marked as invalid). Please follow the automated process for submissions. Contributions to other aspects of the project, outside the icon resource contribution process, are not subject to this restriction.
