# Request Adaptation

> Welcome to contribute valuable resources for ANIP!

## How to Submit

Currently, the way to submit an adaptation request is to create an issue on GitHub.

You need to go to GitHub and create an issue using the notification icon adaptation request template.

A maintainer will review the issue you created, and it will be processed within 1-3 business days.

Once the adaptation is complete, the issue will be closed and marked as completed.
You can get the latest adaptation data by syncing the cloud rules.

If you don't have a GitHub account, please register first, and [click here](repo://issues/new?template=request_adaption.yml) to create an issue immediately.

## Notice Before Submission

Please make sure you have contacted the app developer first if possible,
as we recommend that you contact the app developer to adapt the notification icon themselves before submitting an issue here.

Already have icon adaptation resources? Please go to the [Ready to Submit](./submit.md) page.
